# 仕様

## 機能一覧

| # | 機能 | 概要 |
| :-- | :--- | :--- |
| 1 | 設定ファイル読み込み | `src/config.json` を読み込み、鍵（ローター順序・初期位置・リングセッティング・プラグボード・リフレクター）を得る |
| 2 | 文字列入力 | 標準入力から1行読み取り、英字のみを対象として大文字化する |
| 3 | エニグマ変換 | 読み込んだ鍵で1文字ずつ変換する |
| 4 | 結果出力 | 変換結果を標準出力に表示する |

## 設定ファイル仕様

- パス: `src/config.json`（作業ディレクトリからの相対パス固定。コマンドライン引数・環境変数での変更には対応しない）
- 形式: JSON。フィールドは `enigma.EnigmaKey` に対応する。

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `rotorOrder` | 文字列配列 | 使用するローター名（例: `"I"`〜`"V"`）を左から並べたもの |
| `rotorPositions` | 文字列 | 各ローターの初期位置を表す英字（例: `"ABC"`） |
| `ringSettings` | 数値配列 | 各ローターのリングセッティング（1始まり） |
| `plugboardPairs` | 文字列配列 | プラグボードで交換する2文字ペアの一覧（例: `["AQ", "EP"]`） |
| `reflectorType` | 文字列 | リフレクターの種類（`"B"` または `"C"`） |

設定例（デフォルトの `src/config.json`）:

```json
{
    "rotorOrder": ["III", "II", "I"],
    "rotorPositions": "ABC",
    "ringSettings": [1, 1, 1],
    "plugboardPairs": ["AQ", "EP", "TY"],
    "reflectorType": "B"
}
```

## エラー・メッセージ仕様

| 状況 | メッセージ | 出力先 |
| :--- | :--- | :--- |
| 設定ファイルが存在しない、または読み込みに失敗 | `エラー: <エラー内容>` | 標準エラー出力 |
| 設定ファイルの内容がJSONとして不正 | `エラー: <エラー内容>` | 標準エラー出力 |
| 標準入力の読み取りに失敗 | `エラー: <エラー内容>` | 標準エラー出力 |
| 存在しないローター名を指定 | `Invalid rotor name: <name>`（panic） | プロセス異常終了 |
| 存在しないリフレクター種別を指定 | `Invalid reflector: <name>`（panic） | プロセス異常終了 |
