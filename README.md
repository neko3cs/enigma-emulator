# enigma-emulator
エニグマ暗号機のエミュレーター。Go言語の学習用。

## 仕組み

Go初学者向けに、実装の考え方をざっくり説明します。より詳しい仕様は [`docs/`](docs/) 以下の設計ドキュメントを参照してください。

### エニグマ暗号とは

第二次世界大戦でドイツ軍が使っていた暗号機です。キーボードで打った文字が、複数の「ローター」と「リフレクター」という部品を電気信号が通ることで別の文字に変換されて出力されます。特徴的なのは、**同じ鍵設定で変換すると暗号化と復号の両方ができる**（対称）という点です。本実装もその性質を利用しており、`Encrypt` を2回同じ鍵で通すと元の文字列に戻ります。

### 登場する構造体（Goのstruct）

このプログラムは4つの部品を、それぞれ別のstructとして表現しています（`src/enigma/` 配下）。

| struct | ファイル | 役割 |
| :--- | :--- | :--- |
| `EnigmaKey` | `key.go` | 鍵の設定値（ローター順序・初期位置・リングセッティング・プラグボードの配線・リフレクター種別）をまとめて渡すための入れ物 |
| `Enigma` | `machine.go` | 3本の `Rotor`・1個の `Reflector`・1個の `Plugboard` をまとめて持ち、1文字ずつ変換する司令塔 |
| `Rotor` | `rotor.go` | 文字を別の文字に変換する回転部品。1文字処理するたびに回転（ステップ）する |
| `Reflector` | `reflector.go` | 信号を折り返し、逆方向にローター群を通すための部品 |
| `Plugboard` | `plugboard.go` | 変換の前後で、指定した文字ペアを交換する配線盤 |

Goでは、`type Xxx struct { ... }` で部品（データ）を定義し、`func (x *Xxx) Method() {}` という「ポインタレシーバ」を使ったメソッドでその部品の振る舞いを定義します。たとえば `Rotor` は次のような形です。

```go
type Rotor struct {
    wiring      string // 26文字の変換表（例: "EKMFLGDQVZNTOWYHXUSPAIBRCJ"）
    notch       byte   // 隣のローターを回転させる位置を示す文字
    position    int    // 現在の回転位置（0〜25）
    ringSetting int     // 内部配線と外側表示のずれ
}
```

フィールド名が小文字始まり（`wiring` など）なのは、Goでは**先頭が小文字の識別子は同じパッケージ内からしかアクセスできない**というルールがあるためです。そのため `main.go` からは `Rotor` の中身を直接いじれず、`EnigmaKey` → `NewEnigmaFromKey` → `Encrypt` という公開された入口だけを使うようになっています。

### 1文字を変換する流れ（`EncryptChar`）

`machine.go` の `EncryptChar` が、1文字ごとに以下の順で処理します。

```
入力文字
  ↓ ①ローターを回転させる（ステップ）
  ↓ ②プラグボードで文字を交換
  ↓ ③ローター1〜3を順に通過（Forward）
  ↓ ④リフレクターで折り返す
  ↓ ⑤ローター3〜1を逆順に通過（Backward）
  ↓ ⑥プラグボードで文字を交換
出力文字
```

- **② と ⑥（プラグボード）**: `map[byte]byte` で文字の対応表を持ち、該当すれば交換、無ければそのまま返すだけのシンプルな仕組みです（`plugboard.go`）。
- **③・⑤（ローター通過）**: `wiring` という26文字の文字列が変換表になっており、「何番目の文字か」を数値（インデックス）に変換して `wiring` を引く、という処理を `position`（現在の回転位置）と `ringSetting`（リングのずれ）を考慮しながら行います。`Forward` が行きの変換、`Backward` がその逆変換です。
- **①（ステップ）**: ローターは1文字処理するたびに回転します。さらに、あるローターが特定の位置（`notch`）まで回転すると、隣のローターも巻き込んで回転する「ダブルステッピング」という実機特有の癖を再現しています。

### Goの学習ポイントとして見ておきたい箇所

- **構造体とポインタレシーバ**: `func (r *Rotor) Forward(c byte) byte` のように、構造体の状態を変更・参照するメソッドをポインタで定義するパターン（`rotor.go`）
- **byte型での文字計算**: `int(c-'A')` のように、アルファベットを0〜25の数値として扱い、`% 26` で26文字の範囲に収める剰余演算（`rotor.go`, `machine.go`）
- **mapの利用**: `map[byte]byte` で単純な対応表を表現する例（`plugboard.go`）
- **パッケージ分割とexport制御**: `main` パッケージと `enigma` パッケージを分け、大文字/小文字で公開範囲をコントロールする例（`src/main.go`, `src/enigma/`）
